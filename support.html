Support

Questions or problems? Email mangaloly.dev@gmail.com. Please say which phone and OS version you use.

The pause screen doesn't appear

  • Android: check Usage access and Display over other apps are on for Haltly. Today shows a warning if one is off.
  • Android: let Haltly run in the background. Settings › Apps › Haltly › Battery › Unrestricted. Some brands also have an "Autostart" switch (Xiaomi, Oppo, Vivo, Realme).
  • iPhone: check Settings › Screen Time › Apps with Screen Time access includes Haltly.

It takes a second to appear

On Android, turn on Settings › Precision mode in Haltly. It uses Accessibility only to read which app is in front.

I want to end a block early

Tap Request unlock on the block screen. Without Strict mode it unlocks straight away. With Strict mode there is a 15-minute wait, which you can cancel any time.

How do I delete my data?

Settings › Delete everything, or uninstall Haltly. Nothing is stored anywhere else.

Does Haltly cost anything?

No. Haltly is free, with no ads, no payments and no account.
